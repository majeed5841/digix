# Digix Link - Digital Marketing Agency Website

A modern, conversion-focused multi-page website for Digix Link digital agency.

## 📁 Project Structure

```
digix-link/
├── index.html              # Homepage
├── css/
│   └── style.css           # Main stylesheet
├── js/
│   └── main.js             # JavaScript functionality
├── pages/
│   ├── about.html          # About page
│   ├── services.html       # Services overview
│   ├── contact.html        # Contact page with form
│   └── case-studies.html   # Case studies showcase
└── images/                 # Image assets directory
```

## 🎨 Design Features

- **Modern UI/UX**: Clean SaaS-inspired design with bold typography
- **Color Palette**: Blues, purples, with bright accents
- **Responsive**: Mobile-first design (320px → 1440px+)
- **Animations**: Smooth scroll, fade-in effects, hover interactions
- **8pt Grid System**: Consistent spacing throughout

## 🚀 Key Sections

### Homepage
- Hero section with CTAs
- Trust signals (client logos, stats)
- Services overview (6 cards)
- Process timeline
- Case studies preview
- Testimonials
- USA Map section
- Blog preview
- Final CTA

### Other Pages
- About: Company story, mission, why choose us
- Services: All 6 services with links to detail pages
- Contact: Working form with validation, contact info
- Case Studies: Results-driven project showcases
